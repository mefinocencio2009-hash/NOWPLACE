# 🌍 NowPlace — MVP

Rede social que combina descoberta de lugares (WPlace) com autenticidade do
momento (BeReal). O usuário registra **onde está e o que está fazendo agora**
com duas fotos (ambiente + selfie), localização automática e regra de acesso
ao feed baseada em publicações das últimas 24 horas.
